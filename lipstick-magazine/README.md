# 绯色 ROUGE · 口红杂志

一本以口红为主题的网络杂志（Web Magazine），创刊号包含趋势报道、互动试色、口红编年史与选色指南四个专题。纯静态实现，无需构建，浏览器直接打开即可阅读。

## 快速开始

```bash
# 直接打开封面
open lipstick-magazine/index.html

# 或启动本地服务器（推荐，避免个别浏览器本地文件限制）
cd lipstick-magazine && python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 页面结构

```
lipstick-magazine/
├── index.html            # 封面 + 目录（CSS 绘制口红、条形码、封面标语）
├── pages/
│   ├── trends.html       # 01 · 2026 唇色趋势报告（色卡墙 + 数据看板）
│   ├── swatches.html     # 02 · 互动试色间（点击色卡实时预览上唇效果，哑光/镜面切换）
│   ├── history.html      # 03 · 口红编年史（五千年时间线）
│   └── guide.html        # 04 · 选色完全指南（肤色对照表 / 质地解析 / 护唇手册）
├── css/style.css         # 全局视觉系统（绯红 × 鎏金 × 米白）
└── js/main.js            # 滚动渐显动效
```

## 设计说明

- **视觉系统**：绯红 `#9E1B32` / 酒红 `#5C0A1E` / 鎏金 `#C9A96E` / 米白 `#FAF6F0`
- **字体**：标题 Noto Serif SC（衬线，杂志感），正文 Noto Sans SC
- **版式**：封面采用杂志刊头 + 封面标语 + 条形码的经典结构；内页使用首字下沉、双栏正文、引语分隔线等杂志排版手法
- **零图片依赖**：封面口红、试色嘴唇、色卡均由纯 CSS 绘制
- **响应式**：适配桌面与移动端

## 交互功能

- **互动试色间**：点击 12 款色号色卡，唇部模型实时变色并展示色号档案；支持哑光 / 镜面质地切换
- **滚动渐显**：内页卡片与段落随滚动淡入
